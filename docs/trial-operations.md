# AI Story Studio · 免费试用交付流程

适用对象：前 3 位试用用户。目标是验证“哪种创作交付最有价值”，不是无限制免费接单。

## 0. 先筛选，再承诺

只接受以下条件都满足的申请：

- 有明确故事想法，至少一句话；
- 只选择短剧、漫画、小说中的一种；
- 愿意在收到后回答 5 个反馈问题；
- 理解本次不包含图片、视频、配音、商用授权或多轮无限修改。

不满足时的回复：

> 谢谢你的想法。现在是少量试用阶段，我需要优先验证一个清晰的内容方向。你可以补充一句故事设定和最想解决的问题；名额开放后我会再联系你。

## 1. 15 分钟内回复的确认模板

> 我收到你的试用申请了。你选择的是【形式】，我理解你的核心想法是：【一句话复述】。本次我会交付：故事方向、角色设定，以及一份【形式】小样。它不包含图片或视频生成。完成后请用 5 分钟回答反馈问题；如果以上理解正确，我就开始整理。

若对方没有确认，不开始制作。

## 2. 每位用户的工作记录

复制以下区块到新的本地 Markdown 文件中；不要把用户的联系方式或完整私人故事提交到公开仓库。

```text
编号：Trial-01
日期：
内容形式：短剧 / 漫画 / 小说
一句话创意：
用户最想解决的问题：
确认交付：
约定交付时间：
实际耗时：
是否按时交付：是 / 否
```

## 3. 交付前检查

- [ ] 一句话卖点能复述用户想法，没有擅自改题材。
- [ ] 人物名、关系、年龄与道具前后一致。
- [ ] 短剧：有开场钩子、冲突、结尾悬念；时长合理。
- [ ] 漫画：每格都有画面重点与阅读顺序。
- [ ] 小说：有场景、人物动作、冲突，并留下可续写线索。
- [ ] 文档不包含密钥、用户联系方式或未经许可的私人信息。
- [ ] 写明这是试用小样，后续修改与媒体生成需另行确认。

## 4. 交付消息模板

> 你的试用小样已完成：包含【交付清单】。这份内容主要帮助你确认故事方向与下一步创作，不含图像、视频或商用发布。请先看最想解决的那一部分；如果方便，请回答下面 5 个问题。你的原话会决定我下一轮只改哪一个功能。

## 5. 固定反馈问题

1. 你能在两分钟内说清它帮你做了什么吗？
2. 最有用的一部分是什么？
3. 最困惑、最不相信或最不想继续看的部分是什么？
4. 它帮你节省的是哪一步时间？
5. 如果以后付费，什么交付结果和什么价格你会考虑？

## 6. 试用结束后的决策

三位试用者都完成后，只统计三件事：

| 信号 | 怎么判断 | 下一步 |
| --- | --- | --- |
| 形式偏好 | 至少 2 人主动选择同一种形式 | 优先优化该形式 |
| 价值点 | 至少 2 人提到同一部分最有用 | 把它变成收费服务的核心交付 |
| 最大阻碍 | 至少 2 人卡在同一步 | 下一开发阶段只修复这一步 |

没有出现重复信号时，不开发新功能；继续找 2 位用户验证，而不是凭感觉扩展产品。
