# AI Creator Studio

niccjie 的第二个创作作品：一个探索 AI 辅助故事创作的网页 Demo。输入故事想法，选择短剧、漫画或小说，获得五个维度的创作参考。

## 本地运行

直接用现代浏览器打开本文件夹中的 `index.html` 即可使用，无需安装依赖或构建。

也可以在项目根目录运行：

```sh
python -m http.server 8000
```

然后访问 `http://localhost:8000/ai-story-studio/`。从项目根目录启动可以同时使用「返回作品集」链接。只部署本文件夹时，请将该链接改为个人主页的实际地址。

## 功能

- 输入最多 500 字的故事想法，支持示例填入、字数提示和空输入校验。
- 三种类型：短剧的场景对白、漫画的六格分镜、小说的第一章叙事。
- 点击生成后展示约 1.6 秒加载动画；生成期间禁用表单，避免重复提交。
- 展示故事简介、人物设定、剧情大纲、第一集脚本、AI绘图提示词。
- 支持再次生成及复制完整方案；剪贴板不可用时选中结果，提示手动复制。
- 响应式卡片布局，支持键盘操作、状态播报和减少动态效果偏好。

## 模拟生成说明

当前版本没有接入 GPT 或其他 AI API，没有后端、网络请求、API Key 或输入持久化。刷新页面会清空本次输入和结果。

生成逻辑使用本地示例模板：保留输入作为主题，按类型切换脚本格式和绘图风格。人物与悬念情节是固定的示范骨架，不具备真实语义理解，也不会生成实际图片。界面明确标注模拟状态，适合展示交互和学习前端开发。

## 文件结构

```text
ai-story-studio/
├── index.html   # 页面结构、输入表单和结果区域
├── style.css    # 米白背景、橙色强调、网格及响应式样式
├── script.js    # 模板、表单校验、加载状态、结果渲染与复制
└── README.md
```

纯 HTML、CSS、JavaScript，无第三方依赖或在线字体；本文件夹中的三个页面资源可离线运行。

## 检查方式

1. 空输入点击生成，应提示补充想法。
2. 点击示例按钮，分别选择三种类型生成，确认五个结果区域都有内容且脚本格式不同。
3. 加载期间不能重复提交；完成后可修改主题再次生成。
4. 尝试输入 HTML 标签，结果应按普通文字展示。
5. 在电脑与手机尺寸下检查表单、卡片和长内容换行；用 Tab 操作控件。
6. 测试复制按钮；浏览器限制剪贴板时按提示手动复制。
