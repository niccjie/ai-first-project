# 校园悬疑《未读消息》

> 静态演示案例 · 不含真实模型调用或外部生成费用

## 创作命题

一名学生收到来自失踪好友的定时消息。每一条消息都指向校园里一个被掩盖的秘密；当她找到最后的发送地点，才发现好友并非失踪，而是在保护一份会牵连全校的证据。
