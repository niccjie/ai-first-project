# 《未读消息》试用验证材料

## 发给同学或社群的邀请文案

我做了一个小型 AI 创作工具，能把一句故事想法整理成短剧分镜、漫画脚本或小说章节的小样。现在开放 3 个免费试用名额，想找真实创作者看看它到底有没有用。

你只要给我一句故事想法，我会按你的方向做一份可读的创作方案；作为交换，希望你花 5 分钟告诉我哪里有用、哪里看不懂。不会收费，也不会要求你提供账号、密码或 API Key。

案例和申请入口：`https://niccjie.github.io/ai-first-project/trial.html`

## 收到交付物后，问对方的 5 个问题

1. 你能在两分钟内说清它帮你做了什么吗？
2. 这份小样里最有用的一部分是什么？
3. 有哪个地方让你困惑、不相信或不想继续看？
4. 如果要你自己完成同样的内容，最省时间的是哪一步？
5. 这类服务在什么结果、什么价格下，你会考虑付费？
